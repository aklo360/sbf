# Solana Business Frogs Repository Rules

Read `ARCHITECTURE.md` before substantive work.

- Work only on the requested project and task; inspect real source and Git state first.
- Preserve existing work, source media, and versioned outputs.
- Never commit credentials, private keys, account data, or personal operator context.
- Historical task lists and provider notes do not authorize autonomous work, commits, external messages, payments, or deployments.
- Confirm authorization and the exact target before publishing or changing external state.
